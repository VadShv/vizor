# В(Визор —A — дашборд из вашей таблицы

Загрузите CSV или Excel — Визор автоматически определит типы данных, посчитает метрики и соберёт интерактивный дашборд с графиками и инсайтами. Все данные обрабатываются локально в браузере.

## Возможности

- **Умный разбор** — числа, даты и категории распознаются автоматически, включая русские форматы (`1 234,56 ₽`, `15.03.2025`)
- **Автодашборд** — KPI-карточки, динамика, структура, распределение и взаимосвязи строятся без настройки
- **Инсайты** — автоматические выводы: лидеры, тренды, корреляции, пропуски
- **Поиск и фильтрация** — текстовый поиск по всем колонкам, графики пересчитываются
- **Экспорт CSV** — выгрузка отфильтрованных данных
- **Тёмная тема** — сохраняется между сессиями
- **Демо-наборы** — «Продажи» (900 строк) и «Сотрудники» (250 строк)
- **До 100 000 строк** с предупреждением об обрезке

## Технологии

| Слой | Технология |
|---|---|
| Фреймворк | React 18 |
| Роутинг | wouter (hash-router) |
| Графики | recharts |
| Парсинг | papaparse (CSV) + SheetJS (XLSX, lazy-load) |
| UI | shadcn/ui + Radix UI + Tailwind CSS |
| Сервер | Node.js `http` (static serve) |
| Сборка | Vite + esbuild |
| Тесты | Vitest |

## Быстрый старт

```bash
npm install          # зависимости
npm run dev          # dev-сервер (Vite HMR, порт 5173)
npm run build        # production-сборка (client + server)
npm run start        # запуск production-сервера (порт 5000)
npm test             # unit-тесты (37 тестов)
```

## Деплой

```bash
PORT=3003 npm run start   # запуск на нужном порту
```

Production-сервер раздаёт статику из `dist/public/` с SPA-fallback на `index.html`.
